Portfólio — Emerson William
Portfólio pessoal desenvolvido como atividade do Programa Trilhas, com o objetivo de apresentar minha trajetória, meus projetos e meus certificados na área de desenvolvimento front-end.
O projeto utiliza páginas estáticas e um layout simples, com estilos próprios para cada página.
Tecnologias
- HTML5 para a estrutura das páginas.
- CSS3 para os estilos e a adaptação do layout a diferentes tamanhos de tela.
- Git e GitHub para versionamento e compartilhamento do código.
Páginas
- Início: apresentação pessoal e links para as demais páginas e os certificados.
- Sobre mim: breve apresentação da minha trajetória e dos meus objetivos profissionais.
- Projetos: quatro cards com imagens ilustrativas e links para os repositórios.
Projetos apresentados
Projeto	Descrição	Repositório
Hipócrates	Projeto em grupo desenvolvido no Senac para a área da saúde, com cadastros e agendamento de consultas.	Hipócrates
Rocket Movie	Aplicação para cadastrar filmes, atribuir notas e registrar comentários.	Rocket Movie
Pokédex	Interface para buscar Pokémon pelo nome ou número.	Pokédex
GitFav	Aplicação para consultar e salvar perfis favoritos do GitHub.	GitFav


As capas dos cards foram geradas com inteligência artificial para representar os projetos. Elas não são capturas das aplicações.
Estrutura principal
Arquivo ou pasta	Função
index.html	Página inicial.
style.css	Estilos da página inicial.
sobre.html	Página de apresentação pessoal.
sobre.css	Estilos da página Sobre mim.
projetos.html	Página com os cards de projetos.
projetos.css	Estilos da página Projetos.
assets/	Imagens e ícones utilizados nas páginas.


Como abrir
1. Baixe o projeto ou clone o repositório.
2. Mantenha os arquivos HTML, CSS e a pasta assets na mesma pasta do projeto.
3. Abra o arquivo index.html no navegador.
Não é necessário instalar dependências ou executar um processo de build. Se preferir, abra a pasta no Visual Studio Code e utilize a extensão Live Server.
Como personalizar
- Edite a apresentação em sobre.html.
- Atualize os cards e os links em projetos.html.
- Coloque suas imagens na pasta assets e ajuste os caminhos no HTML ou CSS.
- No botão de certificados em index.html, substitua o valor provisório driver no atributo href pelo link público da sua pasta de certificados no Google Drive.
